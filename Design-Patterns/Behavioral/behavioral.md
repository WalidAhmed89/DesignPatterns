# Behavioral Design Patterns

## Overview

**Behavioral Design Patterns** focus on communication and responsibility between objects.

They describe how objects cooperate, how responsibilities are distributed, and how behavior can vary without creating tightly coupled code.

## Current Project Status

The `Behavioral` package is currently reserved for behavioral pattern implementations.

No behavioral pattern examples are included in the current project.

## Common Behavioral Patterns

Examples of well-known GoF behavioral patterns include:

- Strategy
- Observer
- Command
- State
- Template Method
- Iterator
- Chain of Responsibility
- Mediator
- Memento
- Visitor
- Interpreter
